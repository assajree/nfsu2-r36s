ม็อดภาษาไทย Need for Speed: Underground 2
สำหรับ nfsu2-recompiled-r36s (R36H / R36S / playOS / ArkOS)
.
รายละเอียดม็อด
- มีแค่ม็อดภาษาไทยเท่านั้น ไม่มีตัวเกม
- ใช้ได้กับ nfsu2-recompiled-r36s เท่านั้น (ติดตั้งไว้ใน ports/nfsu2 เรียบร้อยแล้ว)
- ดัดแปลงจากภาษาไทย Official เวอร์ชัน PC สมัยที่ยังมี EA สาขาประเทศไทย
- ปลดล็อกซับไตเติลภาษาไทยสมบูรณ์แบบทั้งฉากการ์ตูนและภาพยนตร์
- รองรับระบบ TUI รวมศูนย์ในไฟล์เดียว (NFSU2_Thai.sh) ไม่รกหน้าเมนู TOOLS
- รองรับปุ่มควบคุม D-Pad และระบบสลับปุ่ม A/B ตามการตั้งค่าของ OS อัตโนมัติ (ทั้ง playOS และ ArkOS)
- ทดสอบแล้วกับ R36H บนระบบ playOS 4 และ dArkOSen-R36
- ไฟล์ติดตั้งมี 2 แบบให้เลือกโหลดตามความสะดวก รายละเอียดอยู่ด้านล่าง
.
==========================================================
แบบที่ 1: ติดตั้งผ่าน TUI Manager (แนะนำ - โหลด nfsu2_thai.zip)
==========================================================
ควบคุมการจัดการทุกอย่างในหน้าจอเมนูเดียว (ติดตั้ง, สลับภาษา, ข้ามวิดีโอ, ถอนการติดตั้ง)

วิธีติดตั้งและใช้งาน:
1. ดาวน์โหลดไฟล์ nfsu2_thai.zip
2. แตกไฟล์ จะได้โฟลเดอร์ nfsu2_thai
3. นำโฟลเดอร์ nfsu2_thai ไปวางไว้ในโฟลเดอร์ tools บน MicroSD Card:
   - playOS: ไดรฟ์ PLAYROMS -> โฟลเดอร์ tools/nfsu2_thai
   - ArkOS: ไดรฟ์ EASYROMS -> โฟลเดอร์ tools/nfsu2_thai
4. การเปิดใช้งานบนตัวเครื่อง:
   - playOS: เปิดแอป File -> เข้า tools/nfsu2_thai -> เลือก NFSU2_Thai.sh กดปุ่ม X แล้วเลือก Run Script
   - ArkOS: เข้าเมนู OPTIONS -> Tools -> nfsu2_thai -> NFSU2_Thai
5. หน้าจอ TUI จะแสดงสถานะและการตั้งค่าปัจจุบันของเกม:
   * กด D-Pad (ขึ้น/ลง) เพื่อเลื่อนตัวเลือก
   * กดปุ่มยืนยัน (Select): ติดตั้ง / ถอนการติดตั้ง / สลับภาษา / ข้ามวิดีโอเปิดเกม
   * กดปุ่มย้อนกลับ (Exit): ออกจากโปรแกรม
   (ปุ่มตกลง/ยกเลิกจะสลับตามที่คุณตั้งค่าไว้ในหน้า OS อัตโนมัติ)
.
==========================================================
แบบที่ 2: ติดตั้งแบบก็อปปี้ไฟล์ลงเครื่องโดยตรง (โหลด nfsu2_thai_copy_paste.zip)
==========================================================
สำหรับผู้ที่ไม่ต้องการรันสคริปต์บนเครื่อง

วิธีติดตั้ง:
1. ดาวน์โหลดไฟล์ nfsu2_thai_copy_paste.zip
2. แตกไฟล์ จะได้โฟลเดอร์ nfsu2 และไฟล์ NFSU2.sh
3. ก็อปปี้ไฟล์และโฟลเดอร์ทั้งหมดไปวางทับใน /roms/ports/ บน MicroSD Card
4. เข้าเล่นเกมตามปกติ ตัวเกมจะเปิดใช้งานภาษาไทยและซับไตเติลทันที
.
