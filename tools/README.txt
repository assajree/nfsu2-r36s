ม็อดภาษาไทย Need for Speed: Underground 2
สำหรับ nfsu2-recompiled-r36s
.
รายละเอียดม็อด
- มีแค่ม็อดภาษาไทยเท่านั้น ไม่มีตัวเกม
- ใช้ได้กับ nfsu2-recompiled-r36s เท่านั้น
- ต้องมี nfsu2-recompiled-r36s ที่ติดตั้งไว้เรียบร้อยแล้ว
- ดัดแปลงจากภาษาไทย Official เวอร์ชัน PC สมัยที่ยังมี EA สาขาประเทศไทย
- ทดสอบแล้วกับ R36H บนระบบ PlayOS 4 และ dArkOSen-R36
- ไฟล์ติดตั้งจะมีสองแบบ ให้เลือกโหลดตามวิธีที่จะใช้ รายละเอียดอยู่ด้านล่าง
- ไฟล์ Setup Script ออกแบบมาให้ใช้ได้กับเครื่องตระกูล R36 และรุ่นอื่นที่มีโครงสร้างเดียวกัน ที่ติดตั้งเกมไว้ใน ports/nfsu2
- รุ่นอื่นที่โครงสร้างไฟล์ไม่เหมือน R36S สามารถใช้วิธี Copy ไฟล์ได้
.
วิธีการติดตั้งใน PlayOS 4
1. ดาวน์โหลดไฟล์ nfsu2_thai.zip
2. แตกไฟล์ nfsu2_thai.zip จะได้โฟลเดอร์ nfsu2_thai
3. ก็อปปี้โฟลเดอร์ nfsu2_thai ไปวางไว้ในโฟลเดอร์ tools บน Partition ที่เก็บเกม (ในคอมพิวเตอร์จะแสดงชื่อไดรฟ์ว่า PLAYROMS)
4. เปิดแอป File แล้วเข้าไปที่ tools/nfsu2_thai
5. เลือกไฟล์ Install_NFSU2_Thai.sh กดปุ่ม X จากนั้นเลือก Run Script จากเมนู
6. รอจนกระทั่ง Script ทำงานเสร็จสมบูรณ์
7. เข้าเล่นเกมภาษาไทยได้ทันทีที่เมนู Ports -> NFSU2
.
วิธีการติดตั้งใน OS ตระกูล ArkOS (ทดสอบกับ dArkOSen-R36)
1. ดาวน์โหลดไฟล์ nfsu2_thai.zip
2. แตกไฟล์ nfsu2_thai.zip จะได้โฟลเดอร์ nfsu2_thai
3. ก็อปปี้โฟลเดอร์ nfsu2_thai ไปวางไว้ในโฟลเดอร์ tools บน Partition ที่เก็บเกม (ในคอมพิวเตอร์จะแสดงชื่อไดรฟ์ว่า EASYROMS)
4. กดปุ่ม Start แล้วเข้าไปตามเมนู OPTIONS -> Tools -> nfsu2_thai -> Install_NFSU2_Thai เพื่อรัน Script
5. รอจนกระทั่ง Script ทำงานเสร็จสิ้น
6. เข้าเล่นเกมภาษาไทยได้ทันทีที่เมนู Ports -> NFSU2
หมายเหตุ:
- ระบบปฏิบัติการอื่น ๆ หน้าต่างเมนูอาจแตกต่างออกไป ให้เลือกเปิดรันไฟล์ Install_NFSU2_Thai.sh เพื่อติดตั้ง
- หากไม่สามารถรันไฟล์ Install_NFSU2_Thai.sh ได้ หรือรันแล้วพบข้อผิดพลาด ให้ใช้วิธี Copy ไฟล์ด้านล่างแทน
.
วิธีการติดตั้งแบบก็อปปี้ไฟล์
1. ดาวน์โหลดไฟล์ nfsu2_thai_copy_paste.zip
2. แตกไฟล์ nfsu2_thai_copy_paste.zip จะได้โฟลเดอร์ nfsu2
3. ก็อปปี้โฟลเดอร์ nfsu2 ไปวางทับโฟลเดอร์ nfsu2 เดิมของตัวเกม
4. เข้าเล่นเกมตามปกติ
ข้อแนะนำ (ไม่ทำก็ได้): ควรสำรองไฟล์เหล่านี้เก็บไว้ก่อน เผื่อกรณีเจอปัญหาจะได้นำไฟล์เดิมกลับมาวางทับได้ทันที
- nfsu2/nfsu2.aarch64
- nfsu2/nfsu2.aarch64.v10
- nfsu2/gamedata/SPEED2.EXE
.
การใช้งาน Script หลังติดตั้ง (ต้องติดตั้งแบบรันสคริปต์เท่านั้น)
หลังจากติดตั้งเสร็จสิ้น ในหน้าจอหมวด TOOLS จะมีเมนูคำสั่งเพิ่มเข้ามาดังนี้
- NFSU2_Language_English.sh: เปลี่ยนภาษาเกมกลับเป็นภาษาอังกฤษ (สำหรับกรณีพบบั๊กการแสดงผลในม็อดภาษาไทย)
- NFSU2_Language_Thai.sh: เปลี่ยนภาษาเกมกลับมาเป็นภาษาไทย
- NFSU2_Toggle_Intro.sh: สลับเปิด/ปิด วิดีโอฉากเปิดเกม (ข้ามโลโก้ EA/THX/Intro เพื่อเข้าเกมไวใน ~1 วินาที)
- Uninstall_NFSU2_Thai.sh: ถอนการติดตั้งม็อดภาษาไทยได้โดยตรงจากตัวเครื่อง
.
ทริกเสริมสำหรับการเล่น
- สามารถกดปุ่ม R3 (กดก้านอนาล็อกขวาลงตรง ๆ) เพื่อเปิดหน้าจอคีย์บอร์ดเสมือน สำหรับใช้ในการตั้งชื่อโปรไฟล์หรือรถ
.
