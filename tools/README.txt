===============
NFSU2 Thai v1.1
===============
🏁 เครื่องมือติดตั้งม็อดภาษาไทยสำหรับ Need for Speed: Underground 2 บน R36S
.
✨ รายละเอียดม็อด
- 🚫มีแค่ม็อดภาษาไทยเท่านั้น ไม่มีตัวเกม
- 🔴ใช้ได้กับ nfsu2-recompiled-r36s เท่านั้น
- ⚠️ต้องมี nfsu2-recompiled-r36s ที่ติดตั้งไว้เรียบร้อยแล้ว
- 💿ดัดแปลงจากภาษาไทย Official เวอร์ชัน PC สมัยที่ยังมี EA สาขาประเทศไทย
- 🕹️ทดสอบแล้วกับ R36H บนระบบ PlayOS 4 และ dArkOSen-R36
- 📦ไฟล์ติดตั้งจะมีสองแบบ ให้เลือกโหลดตามวิธีที่จะใช้ รายละเอียดอยู่ด้านล่าง
- ⚙️ไฟล์ Setup Script ออกแบบมาให้ใช้ได้กับเครื่องตระกูล R36 และรุ่นอื่นที่มีโครงสร้างเดียวกัน ที่ติดตั้งเกมไว้ใน ports/nfsu2
- 🔄รุ่นอื่นที่โครงสร้างไฟล์ไม่เหมือน R36S สามารถใช้วิธี Copy ไฟล์ได้
.
Patch Note v1.1:
-------------------------------------------------------------------------
- แก้ไขข้อความภาษาไทยบนหน้าจอตอนแข่งที่ไม่แสดงผล เช่น ลำดับ, จำนวนรอบ,ข้อความตอนแข่งจบ ให้แสดงภาษาไทยครบทุกโหมด
- แก้ไขสระอิหายในคำว่า "เงิน:" และข้อความภาษาไทยขนาดเล็กบนหน้าจอให้แสดงผลชัดเจน
- เพิ่มการรองรับปุ่มจอย (ปุ่ม X) เปิดใช้งาน GPS นำทางบนแผนที่ (World Map) ได้ทันที
- แก้อาการกระตุกของวิดีโอคัตซีนและอินโทรในเกม 
.
เมนู
-------------------------------------------------------------------------
1. Install/Re-Install NFSU2 Thai: ติดตั้งม็อดภาษาไทย
2. Switch Language: สลับภาษา ไทย/อังกฤษ ได้ เผื่อมีบั๊กในภาษาไทย
3. Skip/Restore Intro Movie: ปิด/เปิด วิดิโอ Intro 
4. Uninstall NFSU2 Thai: ถอนการติดตั้งม็อดภาษาไทย
.
🛠️ วิธีการติดตั้งใน PlayOS 4
-------------------------------------------------------------------------
1. ดาวน์โหลดไฟล์ nfsu2_thai.zip
2. แตกไฟล์ nfsu2_thai.zip จะได้โฟลเดอร์ images, nfsu2thai และไฟล์ NFSU2_Controls.sh, NFSU2_Thai.sh 
3. ก็อปปี้โฟลเดอร์ images, nfsu2thai และไฟล์ NFSU2_Controls.sh, NFSU2_Thai.sh ไปวางไว้ในโฟลเดอร์ ports บน Partition ที่เก็บเกม (ในคอมพิวเตอร์จะแสดงชื่อไดรฟ์ว่า PLAYROMS)
4. ที่เมนูหลักของ Play OS เช้าไปที่ Ports => NFSU2_Thai
5. ทำตามขั้นตอน Install NFSU2 Thai จนเสร็จและกด OK จะกลับมาที่หน้าจอ Play OS
6. เข้าเล่นเกมตามปกติ
.
🛠️ วิธีการติดตั้งใน OS ตระกูล ArkOS (ทดสอบกับ dArkOSen-R36)
-------------------------------------------------------------------------
1. ดาวน์โหลดไฟล์ nfsu2_thai.zip
2. แตกไฟล์ nfsu2_thai.zip 
3. ก็อปปี้โฟลเดอร์ nfsu2thai และไฟล์ NFSU2_Controls.sh, NFSU2_Thai.sh ไปวางไว้ในโฟลเดอร์ tools บน Partition ที่เก็บเกม (ในคอมพิวเตอร์จะแสดงชื่อไดรฟ์ว่า EASYROMS)
4. กดปุ่ม Start แล้วเข้าไปตามเมนู OPTIONS -> Tools -> NFSU2_Thai 
5. ทำตามขั้นตอน Install NFSU2 Thai จนเสร็จและกด OK จะกลับมาที่หน้าจอ Play OS
6. เข้าเล่นเกมตามปกติ
.
หมายเหตุ:
- ระบบปฏิบัติการอื่น ๆ หน้าต่างเมนูอาจแตกต่างออกไป ให้เลือกเปิดรันไฟล์ NFSU2_Thai.sh เพื่อติดตั้ง
- หากไม่สามารถรันไฟล์ NFSU2_Thai.sh ได้ หรือติดตั้งเสร็จแล้วยังไม่เป็นภาษาไทยให้ใช้วิธี Copy ไฟล์ด้านล่างแทน
.

🛠️ วิธีการติดตั้งแบบก็อปปี้ไฟล์
-------------------------------------------------------------------------
1. ดาวน์โหลดไฟล์ nfsu2_thai_copy_paste.zip
2. แตกไฟล์ nfsu2_thai_copy_paste.zip 
3. ก็อปปี้โฟลเดอร์ nfsu2 ไปวางทับไฟล์ไฟล์เดิมของเกม
4. เข้าเล่นเกมตามปกติเกมจะแสดงผลเป็นภาษาไทยแล้ว

ข้อแนะนำ (ไม่ทำก็ได้): ควรสำรองไฟล์เหล่านี้เก็บไว้ก่อน เผื่อกรณีเจอปัญหาจะได้นำไฟล์เดิมกลับมาวางทับได้ทันที
- NFSU2.sh
- nfsu2/nfsu2.cfg
- nfsu2/nfsu2.aarch64
- nfsu2/nfsu2.aarch64.v10
- nfsu2/gamedata/SPEED2.EXE
.
