# NFSU2 R36H — Release Packaging & Thai Installer Asset Invariants

## 1. Keep `dist/*.zip` Synchronized with `tools/nfsu2_thai/`
- Whenever `tools/nfsu2_thai/NFSU2_Thai.sh`, `NFSU2_Controls.sh`, or bundled Thai assets are updated for distribution, always rebuild `dist/nfsu2_thai.zip` via `python3 build_tools_pack.py` and verify contents with `unzip -l`.
- When rebuilding `dist/nfsu2_thai_copy_paste.zip` via `python3 build_copypaste_pack.py`, strip any transient `*.orig_gps` backup files generated by `patch_gps.py`, and do not bundle `nfsu2.aarch64.v12` or unrequested experimental VAO binaries.

## 2. `NFSU2_Thai.sh` Asset Co-Location & Pre-Install Validation
- Bundle `LANGUAGES/Thailand.bin` and `LANGUAGES/LanguageTextures.bin` inside `tools/nfsu2_thai/nfsu2thai/gamedata/`, and bundle the `develop` runtime (`nfsu2.aarch64.v10` and `NFSU2.sh.tmpl`) inside `tools/nfsu2_thai/nfsu2thai/runtime/` (do **not** store `SPEED2.EXE` in `nfsu2thai/gamedata/` or perform on-disk binary/PE patching or `.vp6` file renaming in `NFSU2_Thai.sh`).
- Always name the bundled launcher template `NFSU2.sh.tmpl` (never `.sh`) inside `nfsu2thai/runtime/` so no frontend scanner (`playfe` / EmulationStation) ever exposes it as a menu entry, and install it to `$(dirname "$NFSU2_DIR")/NFSU2.sh` (`chmod 755`).
- Configure `NFSU2_LANG`, `NFSU2_SKIP_INTRO`, `NFSU2_ATTRACT_MODE`, and `NFSU2_SUBTITLES` solely via `nfsu2.cfg`. Restore any legacy `_*.vp6` renames on install/re-install/uninstall/toggle, and on uninstall preserve any restored `nfsu2.cfg` backup's original non-Thai `NFSU2_LANG` instead of forcing `English`.
- Before modifying game files, `NFSU2_Thai.sh` validates that `CARS/CIVIC` and `CARS/RSX` exist (case-insensitive) rather than gating on `SPEED2.EXE` file size, and backs up `nfsu2.aarch64*`, `NFSU2.sh`, `nfsu2.cfg`, and `LanguageTextures.bin` (while still restoring legacy `.backup_thai/SPEED2.EXE` on uninstall if present).
